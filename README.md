#  Form Testing Project (Manual + Automation)

##  Project Overview

This project demonstrates **Manual Testing and Automation Testing** on a web form.

The goal is to validate form functionality using:

* Manual test cases
* Selenium automation (Python)

---

##  Features Covered

###  Manual Testing

* Test case design
* Positive & negative scenarios
* Boundary value testing
* UI validation

###  Automation Testing

* Form filling using Selenium
* Handling:

  * Input fields
  * Radio buttons
  * Checkboxes
  * Textarea
* JavaScript click handling
* Scroll handling
* Assertion (validation of result)

---

##  Test Scenarios

* Valid form submission
* Invalid email validation
* Blank field validation
* Mobile number boundary testing
* Multiple hobbies selection
* Address field validation
